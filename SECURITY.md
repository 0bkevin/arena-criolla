# Security

Please do not report vulnerabilities in public issues. Use [Report a vulnerability](https://github.com/0bkevin/arena-criolla/security/advisories/new) on GitHub to send a private report.

Include the affected URL or file, the steps to reproduce, and the impact. Only the latest version on `main` and the live site at [arenacriolla.com](https://arenacriolla.com/) are supported.
