Publication layout

  public/                 Ready-to-use game art, sound and fonts.
  shared/                 Runtime character, animation and asset metadata.
  docs/                   Private operator instructions.

A normal clone contains everything needed to install, build and play.
No Google Drive download or Git LFS setup is required for this publication.
Research downloads, intermediate artwork, historical reports and captures are
not required to build or run the game and are absent from the current tree.

Private creator accounts, sessions, uploaded photos and generated user storage
under data/ are excluded. .env files and API credentials are also excluded;
.env.example contains configuration names without credentials.
